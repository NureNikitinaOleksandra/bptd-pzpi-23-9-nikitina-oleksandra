# Набір тестів для «Шифр Цезаря та частотний криптоаналіз»

Усі тексти в цьому наборі створені спеціально для тестування. Файли з `plain` — відкритий текст; файли з `cipher_key_N` — той самий текст, зашифрований зсувом `N` за алфавітом програми. Текстові файли збережено в UTF-8.

## Демонстрація викладачу — рекомендований порядок

### 1. Шифрування та дешифрування за відомим ключем

1. Оберіть **Українська мова** → **Шифрування**.
2. Відкрийте `01_uk_plain_sample.txt` будь-яким редактором і вставте текст у поле. Вкажіть ключ `7`, натисніть **Зашифрувати**. Результат має збігатися з `02_uk_cipher_key_7.txt`.
3. Завантажте результат і перевірте його вміст. Перейдіть у **Дешифрування → За відомим ключем**, вставте `02_uk_cipher_key_7.txt`, введіть ключ `7`. Результат має точно збігатися з `01_uk_plain_sample.txt`.
4. Повторіть англійською: `03_en_plain_sample.txt`, ключ `3`, очікуваний шифротекст `04_en_cipher_key_3.txt`.

### 2. Граничні ключі та збереження символів

- Українська: `13_uk_alphabet_for_key_32.txt`, ключ `32`. У межах українського алфавіту зсув на 32 еквівалентний зсуву на один символ вліво; великі/малі літери мають зберегти регістр.
- English: `14_en_alphabet_for_key_25.txt`, ключ `25`. Це еквівалент зсуву на один символ вліво.
- Перевірка незмінних символів: зашифруйте `15_uk_mixed_characters_plain.txt` ключем `7`. Пробіли, цифри, URL, email, лапки, emoji й пунктуація мають залишитися незмінними. Результат очікувано дорівнює `16_uk_mixed_characters_cipher_key_7.txt`.
- Ключ `0`: результат має бути тотожним вхідному тексту.

### 3. Успішна атака частотним аналізом — українська

1. Оберіть **Українська мова** → **Дешифрування → Атака частотним аналізом**.
2. Завантажте `06_uk_attack_cipher_key_7.txt`.
3. Очікувана поведінка: показано графік за всім файлом, матрицю з повторюваними зсувами, список гіпотез, їхні оцінки й короткі фрагменти. Ключ `7` має бути серед повторюваних кандидатів і, для цього спеціально підготовленого тексту, отримати найкращу оцінку.
4. Перевірте, що preview показує лише фрагмент, а завантажений повний результат збігається з `05_uk_attack_plaintext_long.txt`.

### 4. Успішна атака частотним аналізом — English

1. Оберіть **English** та завантажте `08_en_attack_cipher_key_3.txt` у режимі атаки.
2. Ключ `3` має бути серед повторюваних кандидатів і має очолити рейтинг для цього тестового корпусу.
3. Завантажений повний результат має збігатися з `07_en_attack_plaintext_long.txt`.

### 5. Атака чатсотним аналізом, коли 3 та 6 гіпотез

- `18_three_hypotheses_cipher_key_7.txt` ↔ `17_three_hypotheses_plain.txt`
- `20_six_hypotheses_cipher_key_7.txt` ↔ `19_six_hypotheses_plain.txt`

### 7. Перевірка валідації ключа

Окремо в режимах шифрування й дешифрування перевірте:

- порожній текст — повідомлення про необхідність ввести текст;
- порожній ключ;
- ключ `-1`;
- український ключ `33` (поза допустимим діапазоном `0–32`);
- англійський ключ `26` (поза допустимим діапазоном `0–25`);
- дробовий ключ `1.5` (поза допустимим діапазоном)
